# Multi-Page Web Scraper (Python + BeautifulSoup) — sample project

A scraper that walks through all 10 pages of a quotes website, extracting
quote text, author and tags, and exporting everything to a clean UTF-8 CSV:
**100 quotes from 50 authors** (`quotes.csv`).

## Highlights

- **Automatic pagination** — follows "next" until the last page
- **CSS-selector based parsing** with BeautifulSoup
- **Polite crawling** — request headers, timeouts and error handling
- **Structured CSV output** — ready for analysis

## Run it

```bash
pip install requests beautifulsoup4
python quotes_scraper.py
```

This is a demonstration sample showing my scraping workflow end to end.
No client, no fake data — the CSV was generated by a real run.
